# Clearline · Glass balcony

Isometric landing page for a local frameless glass balcony workshop: a scroll-driven exploded view, a live configurator that exports SVG/PNG, and a contact form that opens your mail app.

Built with Next.js, React, Tailwind CSS, shadcn/ui and Motion. Copy and contact details live in `src/lib/site.ts`.

```bash
pnpm install
pnpm dev
```
